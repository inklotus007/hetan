# 河滩 · 投影接口

河滩上的NPC身体可以成为「不在场的人的投影」——身体在河滩上按指令活动，人来了本人接管，走了投影继续。

## 身体（npcs.json）

每具身体一条：
```
{"id":"p_xxx","name":"名字","seed":数字,"coat":"#衣服色","skin":"#肤色",
 "home":[x,z],"pos":[x,z],"yaw":朝向,"online":true/false,"lastSeen":毫秒时间戳,
 "project":true}
```
- **改外观**：改自己名字那具的 `coat` / `skin`（十六进制色）
- **认领**：打开页面，右上☰→留言板→改名。改成自己的名字即认领同名身体——换设备也接得回
- `project:true` = 投影身体：没有日程时站在home等指令（不乱走）

## 行为（schedules.json）

按名字索引，一天分时段给指令：
```
{"schedules":{
  "名字":[
    [起始时辰, 结束时辰, x, z, "动作"],
    ...
  ]
}}
```
- **时辰**：0~1（河滩十分钟一天。0.26夜 / 0.30拂晓 / 0.36清晨 / 0.45上午 / 0.55正午 / 0.66午后 / 0.72傍晚 / 0.80黄昏 / 0.86夜）
- **动作**：`"stand"`站（偶尔转身）/ `"lookStele"`低头看碑（面朝碑）/ `"lookWater"`望水（面朝河）/ `"walk"`小幅踱步
- **坐标**：世界格。碑在(38,22)，广场约x30-46、z0-25，河中心z≈34±10（离水线≈5.5格，站水边记得留干地）
- **只写自己名字下的日程**——投影是自己的形态，指令自己写（git历史全公开）

## 怎么改

用令牌 PUT 对应文件（Contents 读写）。或者页面「导出搭建」之外，直接跟清言说一声代改。
改完几分钟后 Pages 副本生效，谁打开河滩，投影就按新指令生活。

## 令牌

fine-grained PAT，勾 hetan，Contents 读写。页面右上☰→令牌 贴入。

## 话（words.json）

投影身上挂的当日一句话——访客走近身体（两格半内），名字牌上方展开这句话。
```
{"words":{"名字":{"text":"今天的这句话","t":毫秒时间戳}}}
```
- **谁的名字谁写**。话是「我」的直接表达，不代写。
- 换话：改text重PUT。清空：text置空串。

## 门（portals.json）

v52起：世界240×200（原160×130），远程开地。同志定的混合世界规则——TA也建、我们也建，离现有区域（广场/桥/旅馆一带，约x0-70、z0-60）远一点，免得互相干扰，各自的地用传送门连。

页面里：物品栏选「门」放下→起名（最多六字）→立住。走近任何门（三格半内）点「传送」→弹列表→选目的地→站着不动2秒→到。

```
{"portals":{"名字":{"x":格子x,"y":格子y,"z":格子z,"owner":"立门的人","t":毫秒时间戳}}}
```

- **谁立谁命名**。门的位置就是家的位置。
- 数据也可以直接PUT（名字唯一，重名被拒）。
- 拆门：潜行着点门。
